# Character Registration

A project developed for the Programming Language II course taught by Prof. Dr. Roberta. The application allows users to register RPG characters using a graphical user interface built with Java Swing.

## Team Members

- Marcelo Henrique Rocha Filho

## Inheritance

The `Personagem` class serves as the base class, consolidating common character data such as name, difficulty, abilities, and starting level.

The `Mago` (Mage), `Guerreiro` (Warrior), and `Arqueiro` (Archer) classes inherit from `Personagem` and represent the character types available for registration. Each specifies its own class type while reusing the attributes and behaviors defined in the base class.

## How to Run

Run the `App` class to launch the application.
